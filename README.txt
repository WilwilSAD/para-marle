PAGINA PARA MI AMOR
===================

Abre index.html en un navegador.

La carpeta assets/images contiene las 7 fotografías.
La carpeta assets/audio está preparada para los archivos MP3.

IMPORTANTE:
- Si abres index.html directamente, las fotos funcionan.
- Para el audio local, coloca los MP3 en assets/audio con los nombres del README de esa carpeta.
- La función de autoplay se activa al pulsar PLAY; los navegadores pueden impedir autoplay sin interacción.

La página incluye:
- Intro romántica en rojo oscuro.
- Abejas y mariquitas interactivas.
- Mensajes y piropos al hacer clic.
- Tulipanes.
- Reproductor y lista de canciones.
- 7 fotografías con modal animado y textos.
- Botón MÁS.
- Pregunta final SÍ/NO.
- Botón NO que se escapa tras el segundo intento.
- Final tipo Matrix con TE AMO y fuegos artificiales de corazones.
